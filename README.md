# Finance and Business Analysis Excel Projects

This repository contains a collection of Excel-based finance and business analysis projects. The projects cover topics such as cash flow analysis, project valuation, business case development, depreciation, taxes, inflation, and investment decision-making.

These files demonstrate practical skills in financial modeling, data analysis, project evaluation, and spreadsheet-based decision support.

## Project List

| File Name | Description | Key Skills |
|---|---|---|
| `401K Analysis.xlsx` | Analysis of retirement savings and investment growth scenarios. | Investment analysis, future value, Excel modeling |
| `Building the Business Case.xlsx` | Business case preparation to evaluate project feasibility and financial impact. | Business case analysis, financial assumptions, decision-making |
| `Cash Flow Analysis.xlsx` | Analysis of cash inflows and outflows to evaluate financial performance. | Cash flow analysis, financial forecasting, Excel formulas |
| `Depreciation, Taxes, and Inflation.xlsx` | Calculation and analysis of depreciation, tax impact, and inflation effects on financial decisions. | Depreciation methods, tax analysis, inflation adjustment |
| `Project Selection Techniques.xlsx` | Evaluation of different project alternatives using financial selection methods. | NPV, IRR, payback period, project ranking |
| `Project Valuation Techniques.xlsx` | Valuation of projects using financial metrics and investment appraisal methods. | Discounted cash flow, NPV, IRR, project valuation |
| `Project_Building_a_Business_Case.xlsx` | Final business case project applying financial analysis concepts. | Business case development, financial modeling, presentation of findings |
| `DNA_Submission.csv` | Supporting data file used for analysis/submission purposes. | Data handling, CSV processing |

## Skills Demonstrated

## How to Use

1. Download or clone this repository.
2. Open the `.xlsx` files using Microsoft Excel or compatible spreadsheet software.
3. Review the assumptions, calculations, and outputs in each workbook.
4. Use the project files as examples of financial analysis and business decision-making models.
